# דוגמה: גליון הדפסה מתיקיית פרויקט

תיקיית פרויקט לדוגמה: בית הזית, מבנה של 7×10 מ' בשתי קומות של 3.20 מ'.

## הרצה
מתוך שורש הריפו:

```
npm run build
npm run sheet -- examples/sheet-sample
```

## קלט
- assets/logo.svg
- data/project.json
- data/plans.json
- data/materials.json
- data/callouts.json
- data/poem.txt
- data/post.txt

קובץ חסר מושלם מההנחות שב-project.json, והשדות האלה מסומנים source = "assumption".
