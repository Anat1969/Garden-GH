# Garden-GH

אפליקציית תכנון גינות ונוף. קלט: PDF של היתר ומידות. פלט: מודל תלת-ממדי, כתב כמויות, שלבי עבודה ותקציב.

## מסמכים
- CLAUDE.md: הוראות קבועות לכל סשן פיתוח.
- docs/PRD.md: מסמך הדרישות.
- docs/CLAUDE_CODE_PROMPT.md: פרומפט הביצוע ל-Claude Code.

## הפעלה מקומית
```
npm install
npm run dev
```

## משתני סביבה
ראו .env.example. המפתחות לא נשמרים בריפו.
